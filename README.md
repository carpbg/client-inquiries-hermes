# Клиентски запитвания

Регистър и проследяване на клиентски запитвания по процедура CON001.

## Технологии

- TypeScript и React
- Vinext / Vite
- Cloudflare Workers
- Cloudflare D1 (SQLite) чрез Drizzle ORM
- Cloudflare R2 за документи
- Resend за имейл уведомления

## Локално стартиране

Необходими са Node.js 22.13 или по-нова версия и npm.

```bash
npm ci
npm run dev
```

Отворете адреса, показан в терминала. Локалната среда използва локални D1/R2 симулации и не съдържа данните от продукционното приложение.

## Проверка и компилация

```bash
npm test
npm run build
```

## Настройки и тайни

Копирайте `.env.example` като `.env` само за локална работа и попълнете собствени тестови стойности. Никога не качвайте `.env`, API ключове, пароли или експортирани реални данни в GitHub.

Използвани защитени променливи:

- `AUTH_SECRET`
- `APP_SETTINGS_SECRET`
- `RESEND_API_KEY`
- `NOTIFICATION_FROM_EMAIL`

## База данни

Схемата е в `db/schema.ts`, а миграциите са в `drizzle/`. Изходният код не съдържа продукционната D1 база или файловете от R2.

## Публикувана версия

Проектът се публикува чрез ChatGPT Sites. `.openai/hosting.json` пази идентификатора и използваните D1/R2 bindings, но не съдържа тайни.
